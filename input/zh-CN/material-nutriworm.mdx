## 快速答案

**营养虫漂在查克出租车旁的水塔 / 冻结的绿色营养液罐附近**——肥绿的虫悬停在一个固定点位。做查克出租车任务时顺手拿。它们是制作**酒精**的材料（营养虫 x1 + 冰 x2）。

## 在哪里找营养虫

飞到**查克出租车平台**，然后找：

- **出租车平台左侧的水塔结构**——虫悬停在它上方 / 附近
- 有些攻略把同一处地标描述成**查克出租车上方的冻结破损绿色营养液罐**

两者指的都是同一个结构。虫就**漂在明处**——没有藏在任何东西里面。每趟大约刷 **8-12** 只（来自玩家反馈；尚未被更多来源确认）。

> 🐛 **地图标注 bug**：这个刷新点在地图上标的是「Oxyworm gathering spot」（氧虫采集点），多半是 bug。别按地图上的名字找路——按上面说的地标走。也正是这个 bug 让很多玩家「找不到」营养虫。

## 营养虫长什么样

肥绿的**虫**悬浮在一个固定点位——它们是悬停，不像氧虫那样在太空里到处飘。

## 怎么用：酒精配方

打开制作菜单（**C**）制作：

| 配方 | 材料 |
| --- | --- |
| 酒精 Alcohol | 营养虫 x1 + 冰 x2 |

冰来自全图的冰块和结冰残骸——只有虫需要你专门跑一趟。配方在你拿到第一瓶酒精后解锁。

**酒精有什么用：**

- **医疗包**：酒精 x1 + 布料 x2——囤酒精最实在的理由
- **查克出租车任务**：这条任务链最后要给醉酒机器人两杯酒
- **成就**：累计喝 50 瓶（辐射防护 +10）和连续喝 10 瓶（口渴消耗 −5%）

## 营养虫 vs 氧虫

把这两个搞混，就会跑去错的地方找。

| | 营养虫 Nutriworm | 氧虫 Oxyworm |
| --- | --- | --- |
| 用途 | 只用于酒精 | 制氧类制作：纯氧（氧虫 x2 + 金属 x1 + 冰 x1 → +120 氧气） |
| 刷新 | 查克出租车水塔 / 营养液罐旁的固定点位 | 在太空里四处漂 |
| 关联 | 酒精 → 医疗包 / 任务 / 成就 | 「氧虫收藏家」成就，累计采集 300 只（最大氧气 +30） |

氧虫巢穴是另一种独立物体（直接补氧的点位，不是采集氧虫的地方）。

## FAQ

### 1. Breathedge 2 的营养虫在哪里？

查克出租车旁的水塔结构 / 冻结绿色营养液罐附近——肥绿的虫悬在一个点位上。

### 2. 营养虫和氧虫怎么区分？

营养虫 = 绿色，固定在查克出租车一处，只用于做酒精。氧虫 = 在太空里漂，用于制氧类制作。

### 3. 为什么地图上找不到这个刷新点？

已知 bug：地图把它标成「Oxyworm gathering spot」（氧虫采集点）。改按水塔 / 绿色营养液罐这个地标找。

### 4. 怎么做酒精？

在制作菜单里用营养虫 x1 + 冰 x2。配方在你做出第一瓶酒精后解锁。

### 5. 营养虫会刷新吗？

没有记录——每次去的时候按需采集。
