## Quick answer

**Tool modules install at the Workbench; the suit is modified at the Wardrobe.** Modules are removable, break permanently but are recyclable, and base tools never break.

## Steps

1. Install modules on tools at the Workbench (Heft/Edge/Handle slots)
2. Modify the suit at the Wardrobe (Protective modules = armor)
3. Remove intact modules to move them between tools
