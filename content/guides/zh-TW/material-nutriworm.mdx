## 快速答案

**營養蟲漂在查克計程車旁的水塔 / 凍結的綠色營養液罐附近**——肥綠的蟲懸停在一個固定點位。做查克計程車任務時順手拿。它們是製作**酒精**的材料（營養蟲 x1 + 冰 x2）。

## 在哪裡找營養蟲

飛到**查克計程車平臺**，然後找：

- **計程車平臺左側的水塔結構**——蟲懸停在它上方 / 附近
- 有些攻略把同一處地標描述成**查克計程車上方的凍結破損綠色營養液罐**

兩者指的都是同一個結構。蟲就**漂在明處**——沒有藏在任何東西里面。每趟大約刷 **8-12** 只（來自玩家反饋；尚未被更多來源確認）。

> 🐛 **地圖示註 bug**：這個重新整理點在地圖上標的是「Oxyworm gathering spot」（氧蟲採集點），多半是 bug。別按地圖上的名字找路——按上面說的地標走。也正是這個 bug 讓很多玩家「找不到」營養蟲。

## 營養蟲長什麼樣

肥綠的**蟲**懸浮在一個固定點位——它們是懸停，不像氧蟲那樣在太空裡到處飄。

## 怎麼用：酒精配方

開啟製作選單（**C**）製作：

| 配方 | 材料 |
| --- | --- |
| 酒精 Alcohol | 營養蟲 x1 + 冰 x2 |

冰來自全圖的冰塊和結冰殘骸——只有蟲需要你專門跑一趟。配方在你拿到第一瓶酒精後解鎖。

**酒精有什麼用：**

- **醫療包**：酒精 x1 + 布料 x2——囤酒精最實在的理由
- **查克計程車任務**：這條任務鏈最後要給醉酒機器人兩杯酒
- **成就**：累計喝 50 瓶（輻射防護 +10）和連續喝 10 瓶（口渴消耗 −5%）

## 營養蟲 vs 氧蟲

把這兩個搞混，就會跑去錯的地方找。

| | 營養蟲 Nutriworm | 氧蟲 Oxyworm |
| --- | --- | --- |
| 用途 | 只用於酒精 | 製氧類製作：純氧（氧蟲 x2 + 金屬 x1 + 冰 x1 → +120 氧氣） |
| 重新整理 | 查克計程車水塔 / 營養液罐旁的固定點位 | 在太空裡四處漂 |
| 關聯 | 酒精 → 醫療包 / 任務 / 成就 | 「氧蟲收藏家」成就，累計採集 300 只（最大氧氣 +30） |

氧蟲巢穴是另一種獨立物體（直接補氧的點位，不是採集氧蟲的地方）。

## FAQ

### 1. Breathedge 2 的營養蟲在哪裡？

查克計程車旁的水塔結構 / 凍結綠色營養液罐附近——肥綠的蟲懸在一個點位上。

### 2. 營養蟲和氧蟲怎麼區分？

營養蟲 = 綠色，固定在查克計程車一處，只用於做酒精。氧蟲 = 在太空裡漂，用於製氧類製作。

### 3. 為什麼地圖上找不到這個重新整理點？

已知 bug：地圖把它標成「Oxyworm gathering spot」（氧蟲採集點）。改按水塔 / 綠色營養液罐這個地標找。

### 4. 怎麼做酒精？

在製作選單裡用營養蟲 x1 + 冰 x2。配方在你做出第一瓶酒精後解鎖。

### 5. 營養蟲會重新整理嗎？

沒有記錄——每次去的時候按需採集。
