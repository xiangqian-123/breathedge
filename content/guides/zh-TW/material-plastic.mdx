## 快速答案

塑膠來自**平臺邊緣尖刺桿上的灰色球體**。第一顆就在**你自己火車的正上方**——爬上車頂往車頭方向看。用**撬棍**敲破（`Break` 提示，每顆要敲幾下）。

## 塑膠在哪裡找

- **平臺邊緣的尖刺桿**——頂端的灰色球體；最可靠的來源。第一顆就在你的車廂正上方。
- **車站北邊的玻璃走廊**（到處都是窗戶的那條走道）——完好的塑膠球，較少見
- **巨型黃色管道附近**，被切成兩半的車廂旁（車站西北方，漂浮的太空人屍體旁邊）
- 殘骸船艦上硬化的灰色塑膠塊
- 中文攻略：塑膠到處都有，但**以初始車站周圍最密集**，以及黃色管道走廊之後、嚇人車站之前那一段

有一篇攻略標出了多達 5 個塑膠來源、合計約 10 個單位——足夠早期製作與維修。

## 塑膠長什麼樣

兩種描述並存——可能是兩種生成型態：

- 尖刺桿頂端的**灰色球體**（GameRant）
- 附著在管道、破損零件、船殼板與平臺側面的**深色塊狀增生**（AllThings）

用形狀辨認，不要用顏色，兩種都撿。

## 怎麼採集

**撬棍**（Crowbar）搭配 `Break` 提示——要敲幾下才會碎。（有篇攻略說某些來源對切割器有反應——如果 Break 沒反應，試試 Cut。）

## 塑膠有什麼用途

| 用途 | 需要塑膠 |
| --- | --- |
| **採礦器 Thumper**（金屬 x4 + 塑膠 x2） | x2 |
| **切割器 Cutter**（鋁 x4 + 塑膠 x2 + 金屬 x4） | x2 |
| **鑽孔器 Twister**（鋁 x4 + 電線 x2 + 電工膠帶 x3 + 塑膠 x2） | x2 |
| **手電筒 Flashlight**（塑膠 x2 + 電線 x2 + 玻璃 x2 + 燈泡 x1） | x2 |
| **揹包 Backpack**（鋁 x4 + 塑膠 x2 + 鈦 x4 + 電工膠帶 x4） | x2 |
| 營養包製造機 Nutri-Pack-O-Mat 維修 | x1 |

**看到塑膠就敲**——幾乎每個早期工具和揹包都需要它。

> 肚皮塑膠 Bellyplastic 是另一種物品（主線中，舊車站 CZNX 頭目身上的氧蟲幼蟲掉落）。

## 刷新

沒有記錄任何刷新機制。清空的節點就是空的——換下一根桿子，想要同一個點就晚點再回來（它們不會跑掉，但也不會長回來）。

## FAQ

### 1. Breathedge 2 的塑膠在哪裡？
平臺邊緣尖刺桿上的灰色球體——第一顆就在你的火車正上方。

### 2. 什麼工具能敲破塑膠？
撬棍（Crowbar）搭配 Break 提示。每顆球要敲幾下。

### 3. 塑膠為什麼重要？
切割器、採礦器、鑽孔器、手電筒和揹包都需要——看到就敲。

### 4. 塑膠會重生嗎？
未確認——把節點當作一次性。
