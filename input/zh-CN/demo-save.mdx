## 快速答案

**Demo 已被官方推倒重做。** 2025 Next Fest Demo 的内容（火车门密码、出租车任务等）在抢先体验版中**已不适用**，Demo 存档也无法继承。

## Demo 与 EA 的关系

官方多次明确：2025 年的 Demo 是**从零重做的旧版本**，正式 EA 版（2026-08-31）几乎完全推倒重来。因此：

- Demo 时代的攻略（火车门密码、门禁码、旧配方）**大概率已失效**
- Demo 存档**不能继承**到 EA 版
- 请以 EA 版（2026-08-31）的最新攻略为准

## 为什么网上的攻略对不上

如果你看到网上某些攻略和游戏内容对不上，很可能它们是**基于 Demo 版本**写的。认准「Early Access / 2026-08-31」标注的攻略才可靠。
