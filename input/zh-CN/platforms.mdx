Breathedge 2 目前**仅登陆 Windows PC**，主机版尚未公布日期。

## 平台一览

| 平台 | 状态 |
|------|------|
| **Steam（Windows）** | ✅ 已上线（抢先体验） |
| **Epic Games Store（Windows）** | ✅ 已上线（抢先体验） |
| **PlayStation 5** | ❌ 未定（TBA） |
| **Xbox（One / Series X\|S）** | ❌ 未定（TBA） |

## 功能特性

- **单人游戏**：纯单人，无联机/合作模式（官方已明确）。
- **支持手柄**：完全支持 Xbox 控制器。
- **家庭共享**：Steam 支持家庭共享。

## 支持语言

- **音频**：英语、俄语
- **界面 / 字幕文本**（13 种）：英语、法语、德语、西班牙语（西班牙 / 拉丁美洲）、日语、韩语、波兰语、葡萄牙语（巴西）、俄语、**简体中文**、土耳其语、乌克兰语

## 年龄分级

12+（轻度脏话、中度暴力、性暗示内容）。
