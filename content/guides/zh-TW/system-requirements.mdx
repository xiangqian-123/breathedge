Breathedge 2 為 Windows PC 遊戲，配置要求不算高。以下為 Steam 與 Epic 官方一致的配置資料。

## 最低配置

| 專案 | 要求 |
|------|------|
| 作業系統 | 64 位 Windows 10 / 11 |
| 處理器 | Intel Core i5-8400 / AMD Ryzen 5 2600 |
| 記憶體 | 12 GB RAM |
| 顯示卡 | NVIDIA GeForce GTX 1660 6GB / AMD RX 5500 XT 6GB |
| DirectX | 版本 11 |
| 儲存 | 15 GB 可用空間 |

## 推薦配置

| 專案 | 要求 |
|------|------|
| 作業系統 | 64 位 Windows 11 |
| 處理器 | Intel Core i7-13700 / AMD Ryzen 7 7700X |
| 記憶體 | 16 GB RAM |
| 顯示卡 | NVIDIA GeForce RTX 3070 8GB / AMD RX 6700 XT 8GB |
| DirectX | 版本 11 |
| 儲存 | 15 GB 可用空間 |

## 注意事項

- 需要 **64 位處理器和作業系統**。
- 部分第三方網站寫「30 GB 儲存」，與官方「15 GB」不符，**以官方為準**。
- 搶先體驗版體積可能隨更新變化。
