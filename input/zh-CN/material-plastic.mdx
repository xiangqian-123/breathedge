## 快速答案

塑料来自**平台边缘带尖刺杆子上的灰色球体**。第一个就在**你自己列车的正上方**——爬到车顶往车头方向看。用**撬棍**敲碎（`Break` 提示，每个要敲几下）。

## 在哪里找塑料

- **平台边缘带尖刺的杆子**——灰色球体在杆子顶端；最稳定的来源。第一个就在你车厢的正上方。
- 车站北侧的**玻璃走廊**（到处是窗户的那条通道）——有完好的塑料球，但更少见
- **巨型黄色管道附近**，被劈成两半的车厢旁（车站西北方向，一具漂浮的宇航员尸体旁边）
- 失事飞船上的硬化灰色塑料块
- 中文攻略：塑料到处都是，但**开局车站周边最密集**，其次是黄色管道通道之后、吓人车站之前的那一段

有一篇攻略标出了多达 5 处塑料来源、合计约 10 个单位——足够早期制作和维修。

## 塑料长什么样

两种描述并存——很可能是两种刷新形态：

- 尖刺杆子顶端的**灰色球体**（GameRant）
- 附着在管道、破损零件、船体板和平台侧面的**深色块状增生**（AllThings）

按形状辨认，别按颜色，两种都拿。

## 怎么采集

**撬棍**（Crowbar）配合 `Break` 提示——要敲几下才碎。（有一篇攻略说部分来源对切割器有反应——如果 Break 没反应，试试 Cut。）

## 塑料的用途

| 用途 | 所需塑料 |
| --- | --- |
| **采矿器**（金属 x4 + 塑料 x2） | x2 |
| **切割器**（铝 x4 + 塑料 x2 + 金属 x4） | x2 |
| **钻孔器**（铝 x4 + 电线 x2 + 电工胶带 x3 + 塑料 x2） | x2 |
| **手电筒**（塑料 x2 + 电线 x2 + 玻璃 x2 + 灯泡 x1） | x2 |
| **背包**（铝 x4 + 塑料 x2 + 钛 x4 + 电工胶带 x4） | x2 |
| Nutri-Pack-O-Mat 维修 | x1 |

**见到塑料就敲**——几乎每件早期工具和背包都要用。

> 腹塑（Bellyplastic）是另一种物品（由旧车站 CZNX 首领身上的氧虫幼虫掉落，主线相关）。

## 刷新

没有记录到刷新机制。被掏空的节点就一直空着——换一根杆子，想要原地的话可以晚点再回来（它们不会跑，但也不会重新长出来）。

## FAQ

### 1. Breathedge 2 的塑料在哪里？

平台边缘带尖刺杆子上的灰色球体——第一个就在你列车正上方。

### 2. 什么工具能敲开塑料？

撬棍（Crowbar）配合 Break 提示。每个球要敲几下。

### 3. 塑料为什么重要？

切割器、采矿器、钻孔器、手电筒和背包都要用——见到就敲。

### 4. 塑料会刷新吗？

没有确认——把节点当成一次性的。
