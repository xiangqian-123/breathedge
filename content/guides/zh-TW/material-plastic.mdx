## 快速答案

塑膠來自**平臺邊緣帶尖刺杆子上的灰色球體**。第一個就在**你自己列車的正上方**——爬到車頂往車頭方向看。用**撬棍**敲碎（`Break` 提示，每個要敲幾下）。

## 在哪裡找塑膠

- **平臺邊緣帶尖刺的杆子**——灰色球體在杆子頂端；最穩定的來源。第一個就在你車廂的正上方。
- 車站北側的**玻璃走廊**（到處是窗戶的那條通道）——有完好的塑膠球，但更少見
- **巨型黃色管道附近**，被劈成兩半的車廂旁（車站西北方向，一具漂浮的宇航員屍體旁邊）
- 失事飛船上的硬化灰色塑膠塊
- 中文攻略：塑膠到處都是，但**開局車站周邊最密集**，其次是黃色管道通道之後、嚇人車站之前的那一段

有一篇攻略標出了多達 5 處塑膠來源、合計約 10 個單位——足夠早期製作和維修。

## 塑膠長什麼樣

兩種描述並存——很可能是兩種重新整理形態：

- 尖刺杆子頂端的**灰色球體**（GameRant）
- 附著在管道、破損零件、船體板和平臺側面的**深色塊狀增生**（AllThings）

按形狀辨認，別按顏色，兩種都拿。

## 怎麼採集

**撬棍**（Crowbar）配合 `Break` 提示——要敲幾下才碎。（有一篇攻略說部分來源對切割器有反應——如果 Break 沒反應，試試 Cut。）

## 塑膠的用途

| 用途 | 所需塑膠 |
| --- | --- |
| **採礦器**（金屬 x4 + 塑膠 x2） | x2 |
| **切割器**（鋁 x4 + 塑膠 x2 + 金屬 x4） | x2 |
| **鑽孔器**（鋁 x4 + 電線 x2 + 電工膠帶 x3 + 塑膠 x2） | x2 |
| **手電筒**（塑膠 x2 + 電線 x2 + 玻璃 x2 + 燈泡 x1） | x2 |
| **揹包**（鋁 x4 + 塑膠 x2 + 鈦 x4 + 電工膠帶 x4） | x2 |
| Nutri-Pack-O-Mat 維修 | x1 |

**見到塑膠就敲**——幾乎每件早期工具和揹包都要用。

> 腹塑（Bellyplastic）是另一種物品（由舊車站 CZNX 首領身上的氧蟲幼蟲掉落，主線相關）。

## 重新整理

沒有記錄到重新整理機制。被掏空的節點就一直空著——換一根杆子，想要原地的話可以晚點再回來（它們不會跑，但也不會重新長出來）。

## FAQ

### 1. Breathedge 2 的塑膠在哪裡？

平臺邊緣帶尖刺杆子上的灰色球體——第一個就在你列車正上方。

### 2. 什麼工具能敲開塑膠？

撬棍（Crowbar）配合 Break 提示。每個球要敲幾下。

### 3. 塑膠為什麼重要？

切割器、採礦器、鑽孔器、手電筒和揹包都要用——見到就敲。

### 4. 塑膠會重新整理嗎？

沒有確認——把節點當成一次性的。
