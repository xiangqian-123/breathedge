## Quick answer

**Breathedge 2 supports Steam Cloud saves** (listed on the Steam store page), with auto-save in game. Check in-game for the exact Early Access save behavior.

## Steps

1. Make sure Steam Cloud is enabled (Steam client settings)
2. The game auto-saves — no manual save needed
