Breathedge 2 第一章的地點一覽。點選地點名進入單獨攻略（含這裡的任務、材料、成就與危險）。

| 地點 | 簡介 |
|------|------|
| [火車站 Train Station](/zh-TW/guide/location-train-station) | 遊戲開場區域，主線起點。船內可自動補氧，周邊是新手任務的核心區。 |
| [售票建築 Tickets Building](/zh-TW/guide/location-tickets-building) | 火車站附近的售票建築，售票亭任務所在地，有炮塔巡邏。 |
| [公交站 Depot](/zh-TW/guide/location-depot) | 火車站周邊的公交站，多個公交車成就所在地。 |
| [警察局 Police Station](/zh-TW/guide/location-police-station) | 火車站周邊的警察局，炮塔和警察機器人密集，多個成就和支線相關。 |
| [查克計程車 Chuck's Taxi](/zh-TW/guide/location-chucks-taxi) | 最後天線/紀念碑附近的計程車站，大型支線任務所在地。 |
| [天線區 Antenna Area](/zh-TW/guide/location-antenna) | 主線推進到的天線區域（10G 天線），多個支線任務和成就聚集。 |
| [冰凍區域 Frozen Area](/zh-TW/guide/location-frozen-area) | 更遠的寒冷區域，高階材料產地，需要防寒才能深入。 |
| [車站郊區 Station Outskirts](/zh-TW/guide/location-station-outskirts) | 火車站周邊的郊區，大量收集類成就和常見材料所在地。 |

> ⚠️ 地點資訊由支線任務、成就、材料位置交叉整理，搶先體驗版本可能調整。
