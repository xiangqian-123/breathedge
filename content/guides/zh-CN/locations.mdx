Breathedge 2 第一章的地点一览。点击地点名进入单独攻略（含这里的任务、材料、成就与危险）。

| 地点 | 简介 |
|------|------|
| [火车站 Train Station](/zh-CN/guide/location-train-station) | 游戏开场区域，主线起点。船内可自动补氧，周边是新手任务的核心区。 |
| [售票建筑 Tickets Building](/zh-CN/guide/location-tickets-building) | 火车站附近的售票建筑，售票亭任务所在地，有炮塔巡逻。 |
| [公交站 Depot](/zh-CN/guide/location-depot) | 火车站周边的公交站，多个公交车成就所在地。 |
| [警察局 Police Station](/zh-CN/guide/location-police-station) | 火车站周边的警察局，炮塔和警察机器人密集，多个成就和支线相关。 |
| [查克出租车 Chuck's Taxi](/zh-CN/guide/location-chucks-taxi) | 最后天线/纪念碑附近的出租车站，大型支线任务所在地。 |
| [天线区 Antenna Area](/zh-CN/guide/location-antenna) | 主线推进到的天线区域（10G 天线），多个支线任务和成就聚集。 |
| [冰冻区域 Frozen Area](/zh-CN/guide/location-frozen-area) | 更远的寒冷区域，高级材料产地，需要防寒才能深入。 |
| [车站郊区 Station Outskirts](/zh-CN/guide/location-station-outskirts) | 火车站周边的郊区，大量收集类成就和常见材料所在地。 |

> ⚠️ 地点信息由支线任务、成就、材料位置交叉整理，抢先体验版本可能调整。
