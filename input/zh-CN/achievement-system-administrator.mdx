## 快速答案

推进到「PornHubble」处，先破坏主面板旁的 4 个小型缓存，再破坏对面的那个大型缓存。

## 成就信息

| 项目 | 内容 |
| --- | --- |
| 英文名 | System Administrator |
| 全球解锁率 | 27.8% |
| 分类 | 第一章 |
| 属性奖励 | 耐寒防护 +5 |

## 官方描述

> Anyone can handle a computer. Especially when the task is to break it. Proven by millions of sysadmins across the galaxy.


中文意译：谁都会摆弄电脑，尤其是任务是把电脑搞坏的时候。全银河数百万系统管理员早已证明这一点。

## 属性奖励

解锁后永久获得 **耐寒防护 +5**。 成就奖励可以叠加，可在游戏内「奖励」界面查看效果。
