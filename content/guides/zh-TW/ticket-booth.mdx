## 快速答案

售票亭在 **Tickets 建築左側、炮塔旁**。用**金屬 x3 + 電工膠帶 x2 + 電子元件 x1** 修好閃爍的那一側，然後解旋鈕謎題：**第一個向下、第二個向上、第三個向右**——掉出一個代幣。再修好**後辦公室控制檯**（金屬 x4 + 電工膠帶 x1 + 電線 x2 + 電子元件 x2），即可永久關閉炮塔。

## 位置

售票亭位於 **Tickets 車站建築左側**。先找到炮塔，然後繞到它的左側。

![Breathedge 2 實機截圖——「修理售票亭」任務提示](/images/guides/ticket-booth-repair.jpg)

## 應對炮塔

炮塔是**動作感應**的：開火前會先變**紅**。**它變紅時站著別動**，它就不會射擊。

主線的天線任務只能**削弱**炮塔——用切割器切斷磨破處的那兩根黃色線纜，拔出四個冷卻單元 / 電池，再用撬棍砸掉頂部的控制面板。做完這些它仍然能轉動和射擊。想**永久**關掉它，唯一辦法是下面說的後辦公室控制檯。

> 這是可選支線——想什麼時候做都行，不會卡主線。

## 維修材料

售票亭**閃爍的那一側**需要：

| 材料 | 數量 |
| --- | --- |
| 金屬 Metal | x3 |
| 電工膠帶 Electrical Tape | x2 |
| 電子元件 Electronics | x1 |

## 旋鈕謎題答案

提示：Tickets 建築背面有文字 **"Racket"** 和箭頭。到售票亭正面扭旋鈕：

1. **第一個旋鈕：向下**
2. **第二個旋鈕：向上**
3. **第三個旋鈕：向右**

轉對後，機器裡會掉出一個 **代幣 Token**。社羣攻略說代幣用於主平臺上的售賣機——具體用途沒有完整記錄。

## 後辦公室 — 永久關閉炮塔

繞到**建築外側轉到後方**，開啟後門（不是正門）。修復裡面的控制檯：

| 材料 | 數量 |
| --- | --- |
| 金屬 Metal | x4 |
| 電工膠帶 Electrical Tape | x1 |
| 電線 Wires | x2 |
| 電子元件 Electronics | x2 |

這會**永久關閉炮塔**。

## 獎勵

- **主平臺上的售賣機可以使用了**，出售冰、食物和水
- 炮塔被永久關閉，後續探索更安全

## FAQ

### 1. Breathedge 2 的售票亭在哪裡？

Tickets 建築左側、炮塔旁——繞著炮塔的左側走過去就能到。

### 2. 我修好了售票亭，但售賣機不能用。

解旋鈕謎題（下、上、右）——只修好還不夠，代幣來自謎題。

### 3. 主線做完之後炮塔還在射擊。

主線只能讓炮塔慢下來。永久關閉需要修好後辦公室裡的控制檯。

### 4. 怎麼繞過炮塔？

注意它開火前會變紅——變紅時別動，不變紅時移動。然後從左側繞到售票亭。

### 5. 後辦公室的入口在哪裡？

在建築外側繞到後方——走後面的門，不是正門。
