## 快速答案

做出**採礦器 Thumper**（金屬 x4 + 塑膠 x2），離開火車，到車站郊區小行星帶鑽採**大型岩石上的橘銀色礦斑**。**不要去找火車附近的小塊散落殘骸**——鋁只在大顆小行星上。

## 鋁在哪裡找

**車站郊區小行星帶**——從火車／基地出口直直往外飛。專注在**大型漂浮岩石**，不是碎片或小殘骸。確切座標攻略刻意不公開（也未經證實）——掃蕩那些大石頭。

## 鋁長什麼樣

**橘銀色礦斑**混在灰色小行星表面裡——遠看就像普通的岩石紋理。飛到幾公尺內，直到出現**「鋁礦床 Aluminum deposits」標籤 + Drill 提示**。那個提示是辨認礦脈唯一可靠的方法。

![Breathedge 2 實機截圖——Aluminum deposits HUD 標籤](/images/guides/aluminum-deposits.jpg)

## 需要的工具：採礦器 Thumper

**採礦器 Thumper**（鑽機）是必需的：

- 裝備它，靠近礦床，**按住採礦**
- **撬棍和切割器對鋁礦床完全沒用**——這是玩家以為鋁不存在的第一大原因

**從零開始做採礦器**：在火車附近撿 2 個金屬 → 製作**撬棍**（金屬 x2）→ 撬開有標記的容器取得金屬與塑膠 → 製作**採礦器**（金屬 x4 + 塑膠 x2）。

## 鋁有什麼用途

| 用途 | 需要鋁 |
| --- | --- |
| **切割器 Cutter**（鋁 x4 + 塑膠 x2 + 金屬 x4） | x4 |
| **鑽孔器 Twister**（鋁 x4 + 電線 x2 + 電工膠帶 x3 + 塑膠 x2） | x4 |
| **氣罐 Gas Tank**（電線 x4 + 精煉金屬 x2 + 橡膠 x2 + 鋁 x4） | x4 |
| **揹包 Backpack**（鋁 x4 + 塑膠 x2 + 鈦 x4 + 電工膠帶 x4） | x4 |

核心套裝合計 **16 個**。優先順序：**先做切割器**（它卡著火車維修），然後留 4 個給解鎖後的鑽孔器。

## 採不了鋁？

1. **沒裝備採礦器？** 撬棍／切割器對礦床無效
2. **節點已經枯竭？** 飛去下一顆大石頭
3. **距離太遠？** Drill 提示只在幾公尺內出現
4. **看不到任何礦脈？** 放慢速度繞著岩石飛——礦斑藏在灰色紋理裡
5. **氧氣？** 帶冰或純氧，別只帶剛好回程的空氣就出門

> ⚠️ 每個節點的產量（攻略說 2）和刷新時間在目前版本未經證實——不要按固定數量做規劃。

## FAQ

### 1. Breathedge 2 的鋁在哪裡？
車站郊區小行星帶——大型岩石上的橘銀色礦斑，不是火車附近的小殘骸。

### 2. 為什麼我採不了鋁？
你需要採礦器 Thumper。撬棍和切割器對鋁礦床無效。

### 3. 怎麼辨認鋁礦脈？
飛近大型小行星，直到出現「鋁礦床」+ Drill 提示——礦斑遠看就像岩石紋理。

### 4. 我需要多少鋁？
核心套裝 16 個：切割器 x4、鑽孔器 x4、氣罐 x4、揹包 x4。

### 5. 鋁會重生嗎？
未確認——去挖新的岩石，不要等。
