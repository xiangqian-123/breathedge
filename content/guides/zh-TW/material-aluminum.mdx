## 快速答案

做出**採礦器**（金屬 x4 + 塑膠 x2），離開列車，在車站郊區小行星帶**大塊岩石上的橙銀色礦斑**處開採。**別在列車周邊那些零散小廢料裡找**——鋁只在大塊小行星上。

## 在哪裡找鋁

**車站郊區小行星帶**——從列車 / 基地出口直著飛出去。重點看**大塊漂浮岩石**，不是碎屑或小散料。攻略故意不公佈確切座標（也沒有驗證過）——把大石頭一塊塊掃過去。

## 鋁長什麼樣

**橙銀色的礦斑**混在灰色小行星表面裡——遠看就是普通的岩石紋理。飛到幾米之內，直到出現 **「Aluminum deposits」標籤 + Drill 提示**。這個提示是識別礦脈唯一可靠的依據。

![Breathedge 2 實機截圖——Aluminum deposits HUD 標籤](/images/guides/aluminum-deposits.jpg)

## 需要的工具：採礦器

**採礦器**（鑽機）是必需的：

- 裝備它，靠近礦點，**按住開採**
- **撬棍和切割器對鋁礦點完全無效**——這是玩家以為「鋁不見了」的頭號原因

**從零開始拿採礦器**：在列車附近撿 2 份金屬 → 製作**撬棍**（金屬 x2）→ 撬開帶標記的容器拿金屬和塑膠 → 製作**採礦器**（金屬 x4 + 塑膠 x2）。

## 鋁的用途

| 用途 | 所需鋁 |
| --- | --- |
| **切割器**（鋁 x4 + 塑膠 x2 + 金屬 x4） | x4 |
| **鑽孔器**（鋁 x4 + 電線 x2 + 電工膠帶 x3 + 塑膠 x2） | x4 |
| **氣罐**（電線 x4 + 精煉金屬 x2 + 橡膠 x2 + 鋁 x4） | x4 |
| **揹包**（鋁 x4 + 塑膠 x2 + 鈦 x4 + 電工膠帶 x4） | x4 |

核心套裝合計 **16 個**。優先順序：**先做切割器**（它卡著列車維修），然後為鑽孔器留 4 個。

## 採不了鋁？

1. **沒裝備採礦器？** 撬棍 / 切割器對礦點無效
2. **礦點已經被採空了？** 飛去下一塊大石頭
3. **離得太遠？** Drill 提示只在幾米內出現
4. **看不到礦脈？** 減速繞著石頭飛——礦斑藏在灰色紋理裡
5. **氧氣夠嗎？** 帶上冰或純氧，別隻帶夠回去的量就出門

> ⚠️ 每個節點的產量（攻略說 2 個）和重新整理時間在當前版本都未經驗證——別按固定數量做規劃。

## FAQ

### 1. Breathedge 2 的鋁在哪裡？

車站郊區小行星帶——大塊岩石上的橙銀色礦斑，不是列車旁的小散料。

### 2. 為什麼我採不了鋁？

你需要採礦器。撬棍和切割器對鋁礦點無效。

### 3. 怎麼找鋁礦脈？

飛近大塊小行星，直到出現「Aluminum deposits」+ Drill 提示——礦斑遠看和岩石紋理一樣。

### 4. 我需要多少鋁？

核心套裝 16 個：切割器 x4、鑽孔器 x4、氣罐 x4、揹包 x4。

### 5. 鋁會重新整理嗎？

沒有確認——去挖新石頭，別乾等。
