本页汇总 Breathedge 2 第一章已确认的资源，按「基础材料 / 高级材料 / 生物材料 / 燃料」分类，附获取位置。

## 基础材料（10 种）

| 材料 | 获取位置 / 方式 |
|------|------|
| **金属 Metal** | 太空漂浮金属球、旧洗衣机等残骸拆解 |
| **塑料 Plastic** | 残骸拆解，多次敲击才掉落 |
| **铝 Aluminum** | 小行星矿石节点，需采矿器 Thumper 开采 |
| **玻璃 Glass** | 碎片 / 残骸 |
| **电线 Wires** | 电子设备、电视拆解 |
| **电子元件 Electronics** | 旧电视、设备拆解 |
| **强力胶带 Duct Tape** | 残骸 / 探索拾取 |
| **电工胶带 Electrical Tape** | 火车站台边缘红色管道（约 4 根，每根 2 单位，需切割器 Cutter） |
| **布料 Fabric** | 首次采集解锁医疗包配方 |
| **灯泡 Light Bulb** | 拧下灯具上的灯泡 |

## 高级材料

| 材料 | 获取位置 / 方式 |
|------|------|
| **精炼金属 Refined Metal** | 冰冻区域 |
| **钛 Titanium** | 更远区域（后期，做背包 / 喷雾器） |
| **橡胶 Rubber** | 待确认（修引擎需要，约 4 单位） |

## 生物材料

| 材料 | 说明 |
|------|------|
| **氧虫 Oxyworm** | 漂浮蠕虫，做纯氧 / 氧气罐，也可直接吸氧 |
| **营养虫 Nutriworm** | 做酒精的原料 |

## 燃料与其他

| 材料 | 说明 |
|------|------|
| **燃料 Fuel** | 载具 / 引擎相关 |
| **冰 Ice** | 制氧机 + 水壶的原料，也是嚼冰补水的来源 |

## 采集提示

- 见到新材料**至少捡一个**，能触发新配方解锁。
- **塑料是刚需**：修大量设备都要塑料，见到就拆。
- **电工胶带**容易漏掉：它藏在火车站台边缘、融入工业背景的半损坏红色管道上，别只搜台面。

> ⚠️ 抢先体验版本资源分布可能调整，具体以游戏内为准。
