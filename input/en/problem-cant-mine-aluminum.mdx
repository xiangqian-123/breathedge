## Quick answer

**You need the Thumper.** Aluminum sits on asteroid ore nodes that the Scrap can't mine — craft the Thumper (Metal x4 + Plastic x2) first, then mine the nodes.

## Steps

1. Check whether you're holding the Scrap or the Thumper (only the Thumper mines aluminum)
2. If no Thumper: craft it with Metal x4 + Plastic x2
3. Fly to an asteroid ore node and mine it with the Thumper
