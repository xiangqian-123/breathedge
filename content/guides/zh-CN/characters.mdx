Breathedge 2 延续一代的世界观，主角与一群荒诞同伴一起对抗 Breathedge 公司。以下为已确认的主要角色。

## 主角与同伴

| 角色 | 说明 |
|------|------|
| **男人 Man** | 主角，一名普通幸存者，用废料、胶带和各种「有问题的机器」解决麻烦 |
| **战斗服 Suit** | 贴身 AI，会吐槽，带回一只可升级的机械抓取臂 |
| **鸡 Chicken** | 不死鸡，系列吉祥物，一路跟随 |

## NPC 与机器人

| 角色 | 说明 |
|------|------|
| **Babe** | 主线关键 NPC，需要你帮忙修窗户、找胶带 |
| **服务员机器人 Attendant** | 火车站旁损坏的机器人，修好她可获物理防护加成 |
| **棺材机器人 Coffinbot** | 一代延续下来的角色 |
| **流浪汉 Bum** | 与「床垫遭遇战 Battle for the Mattress」相关，击败后可获生命上限加成 |

## 待确认角色（EA 版细节未完全验证）

| 角色 | 说明 |
|------|------|
| **工头 Foreman** | 实况中出现的角色名，与设备校准相关，EA 版细节待确认 |
| **查克 Chuck** | 出租车司机机器人，一代 Demo 中的出租车任务角色，EA 版是否保留待确认 |

## 敌人与生物

第一章会遇到：飞行蠕虫、吐痰鼹鼠、尖叫幼虫、碱鼹鼠，以及修复机器人、警察机器人、拾荒机器人。机器人会按自己的路线巡逻、追你或逃跑，是资源来源但不好对付。

> ⚠️ 抢先体验版角色与任务线可能随更新扩展，标注「待确认」的角色以游戏内为准。
