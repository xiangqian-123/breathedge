## Quick answer

Breathedge 2 uses standard **WASD movement with mouse-look**, plus **Space/Ctrl** to thrust up/down. The game only shows keybind hints **once at the start**, then you have to find them in the settings menu. The table below is the **community-reported layout** — it is not yet verified in-game, so check **Settings → Controls** for the authoritative list.

> ⚠️ Community-sourced from multiple guides (magicgameworld, 18183, ali213 and others). Minor discrepancies exist between sources (e.g. one omits the F5/F9 quick-save keys), so the in-game settings screen is the definitive reference.

## Movement & flight

| Action | Default key |
|---|---|
| Forward / Left / Back / Right | W / A / S / D |
| Look around | Mouse |
| Move up (thrust) | Space |
| Move down | Ctrl |
| Accelerate (needs gas) | Shift |
| Brake (also breaks turret locks) | Alt |

## Hands & tools

| Action | Default key |
|---|---|
| Left hand | Left Mouse Button |
| Right hand | Right Mouse Button |
| Reload | R |
| Flashlight (after crafting it) | F |
| Quick access panel | Q |
| Menu | Esc |

## Slots, menus & saves

| Action | Default key |
|---|---|
| Hotbar slots | 1 – 0 |
| Inventory | Tab |
| Crafting | G |
| Map | M |
| Journal | J |
| Diary | V |
| Encyclopedia | H |
| Collection | C |
| Control hints | X |
| Hide HUD | Insert |
| Quick save | F5 |
| Quick load | F9 |

## Rebind & quick tips

- **Rebind hotbar items** by dragging them with the left mouse button, or via the right-click action menu.
- In the **inventory**, press **T** on an item to jump to its encyclopedia page; **Z** or **C** quickly sorts items by category.
- **Xbox controller** bindings are also supported (community-reported).

## FAQ

### 1. Where do I see the full keybinds?
**Settings → Controls.** The game only reminds you once at the start, then you look them up there.

### 2. Can I rebind keys in Breathedge 2?
Yes — you can drag hotbar items to rebind them, and the settings menu holds the other bindings.

### 3. Does Breathedge 2 support a controller?
Yes — Xbox controller bindings are supported, though the PC keyboard layout is the most documented.
