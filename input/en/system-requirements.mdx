Breathedge 2 is a Windows PC game with modest requirements. Below are the specs, consistent across Steam and Epic.

## Minimum

| Component | Requirement |
|------|------|
| OS | 64-bit Windows 10 / 11 |
| CPU | Intel Core i5-8400 / AMD Ryzen 5 2600 |
| Memory | 12 GB RAM |
| GPU | NVIDIA GeForce GTX 1660 6GB / AMD RX 5500 XT 6GB |
| DirectX | Version 11 |
| Storage | 15 GB available |

## Recommended

| Component | Requirement |
|------|------|
| OS | 64-bit Windows 11 |
| CPU | Intel Core i7-13700 / AMD Ryzen 7 7700X |
| Memory | 16 GB RAM |
| GPU | NVIDIA GeForce RTX 3070 8GB / AMD RX 6700 XT 8GB |
| DirectX | Version 11 |
| Storage | 15 GB available |

## Notes

- A **64-bit processor and OS** are required.
- Some third-party sites list "30 GB storage" — the official figure is **15 GB**; go with the official number.
- Early Access size may change with updates.
