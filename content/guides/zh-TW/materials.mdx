本頁彙總 Breathedge 2 第一章已確認的資源，按「基礎材料 / 高階材料 / 生物材料 / 燃料」分類，附獲取位置。

## 基礎材料（10 種）

| 材料 | 獲取位置 / 方式 |
|------|------|
| **金屬 Metal** | 太空漂浮金屬球、舊洗衣機等殘骸拆解 |
| **塑膠 Plastic** | 殘骸拆解，多次敲擊才掉落 |
| **鋁 Aluminum** | 小行星礦石節點，需採礦器 Thumper 開採 |
| **玻璃 Glass** | 碎片 / 殘骸 |
| **電線 Wires** | 電子裝置、電視拆解 |
| **電子元件 Electronics** | 舊電視、裝置拆解 |
| **強力膠帶 Duct Tape** | 殘骸 / 探索拾取 |
| **電工膠帶 Electrical Tape** | 火車站臺邊緣紅色管道（約 4 根，每根 2 單位，需切割器 Cutter） |
| **布料 Fabric** | 首次採集解鎖醫療包配方 |
| **燈泡 Light Bulb** | 擰下燈具上的燈泡 |

## 高階材料

| 材料 | 獲取位置 / 方式 |
|------|------|
| **精煉金屬 Refined Metal** | 冰凍區域 |
| **鈦 Titanium** | 更遠區域（後期，做揹包 / 噴霧器） |
| **橡膠 Rubber** | 待確認（修引擎需要，約 4 單位） |

## 生物材料

| 材料 | 說明 |
|------|------|
| **氧蟲 Oxyworm** | 漂浮蠕蟲，做純氧 / 氧氣罐，也可直接吸氧 |
| **營養蟲 Nutriworm** | 做酒精的原料 |

## 燃料與其他

| 材料 | 說明 |
|------|------|
| **燃料 Fuel** | 載具 / 引擎相關 |
| **冰 Ice** | 製氧機 + 水壺的原料，也是嚼冰補水的來源 |

## 採集提示

- 見到新材料**至少撿一個**，能觸發新配方解鎖。
- **塑膠是剛需**：修大量裝置都要塑膠，見到就拆。
- **電工膠帶**容易漏掉：它藏在火車站臺邊緣、融入工業背景的半損壞紅色管道上，別隻搜檯面。

> ⚠️ 搶先體驗版本資源分佈可能調整，具體以遊戲內為準。
