## 快速答案

在火车出口附近锁着的 CAB DOOR 键盘上输入 0861。密码也可以从火车车厢前段看到。

## 成就信息

| 项目 | 内容 |
| --- | --- |
| 英文名 | Hacker |
| 全球解锁率 | 27.7% |
| 分类 | 探索 |
| 属性奖励 | 最大生命 +10 |

## 官方描述

> Any password can be cracked, especially if you already know it and carefully type it in from a piece of paper.


中文意译：任何密码都能破解，尤其是你已经知道、还小心翼翼照着纸条输入的时候。

## 属性奖励

解锁后永久获得 **最大生命 +10**。 成就奖励可以叠加，可在游戏内「奖励」界面查看效果。
