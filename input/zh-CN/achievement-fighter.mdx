## 快速答案

前往公交站，与 Granny 旁边的那扇窗户互动，连续尝试用力推开窗户 3 次以触发成就。

## 成就信息

| 项目 | 内容 |
| --- | --- |
| 英文名 | Fighter |
| 全球解锁率 | 23.0% |
| 分类 | 探索 |
| 属性奖励 | 耐寒防护 +5 |

## 官方描述

> Only a real man would dare oppose a granny on a bus.


中文意译：只有真正的男人才敢在公交车上和老太太作对。

## 属性奖励

解锁后永久获得 **耐寒防护 +5**。 成就奖励可以叠加，可在游戏内「奖励」界面查看效果。
