Breathedge 2 为 Windows PC 游戏，配置要求不算高。以下为 Steam 与 Epic 官方一致的配置数据。

## 最低配置

| 项目 | 要求 |
|------|------|
| 操作系统 | 64 位 Windows 10 / 11 |
| 处理器 | Intel Core i5-8400 / AMD Ryzen 5 2600 |
| 内存 | 12 GB RAM |
| 显卡 | NVIDIA GeForce GTX 1660 6GB / AMD RX 5500 XT 6GB |
| DirectX | 版本 11 |
| 存储 | 15 GB 可用空间 |

## 推荐配置

| 项目 | 要求 |
|------|------|
| 操作系统 | 64 位 Windows 11 |
| 处理器 | Intel Core i7-13700 / AMD Ryzen 7 7700X |
| 内存 | 16 GB RAM |
| 显卡 | NVIDIA GeForce RTX 3070 8GB / AMD RX 6700 XT 8GB |
| DirectX | 版本 11 |
| 存储 | 15 GB 可用空间 |

## 注意事项

- 需要 **64 位处理器和操作系统**。
- 部分第三方网站写「30 GB 存储」，与官方「15 GB」不符，**以官方为准**。
- 抢先体验版体积可能随更新变化。
