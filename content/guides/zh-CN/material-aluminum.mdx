## 快速答案

做出**采矿器**（金属 x4 + 塑料 x2），离开列车，在车站郊区小行星带**大块岩石上的橙银色矿斑**处开采。**别在列车周边那些零散小废料里找**——铝只在大块小行星上。

## 在哪里找铝

**车站郊区小行星带**——从列车 / 基地出口直着飞出去。重点看**大块漂浮岩石**，不是碎屑或小散料。攻略故意不公布确切坐标（也没有验证过）——把大石头一块块扫过去。

## 铝长什么样

**橙银色的矿斑**混在灰色小行星表面里——远看就是普通的岩石纹理。飞到几米之内，直到出现 **「Aluminum deposits」标签 + Drill 提示**。这个提示是识别矿脉唯一可靠的依据。

## 需要的工具：采矿器

**采矿器**（钻机）是必需的：

- 装备它，靠近矿点，**按住开采**
- **撬棍和切割器对铝矿点完全无效**——这是玩家以为「铝不见了」的头号原因

**从零开始拿采矿器**：在列车附近捡 2 份金属 → 制作**撬棍**（金属 x2）→ 撬开带标记的容器拿金属和塑料 → 制作**采矿器**（金属 x4 + 塑料 x2）。

## 铝的用途

| 用途 | 所需铝 |
| --- | --- |
| **切割器**（铝 x4 + 塑料 x2 + 金属 x4） | x4 |
| **钻孔器**（铝 x4 + 电线 x2 + 电工胶带 x3 + 塑料 x2） | x4 |
| **气罐**（电线 x4 + 精炼金属 x2 + 橡胶 x2 + 铝 x4） | x4 |
| **背包**（铝 x4 + 塑料 x2 + 钛 x4 + 电工胶带 x4） | x4 |

核心套装合计 **16 个**。优先级：**先做切割器**（它卡着列车维修），然后为钻孔器留 4 个。

## 采不了铝？

1. **没装备采矿器？** 撬棍 / 切割器对矿点无效
2. **矿点已经被采空了？** 飞去下一块大石头
3. **离得太远？** Drill 提示只在几米内出现
4. **看不到矿脉？** 减速绕着石头飞——矿斑藏在灰色纹理里
5. **氧气够吗？** 带上冰或纯氧，别只带够回去的量就出门

> ⚠️ 每个节点的产量（攻略说 2 个）和刷新时间在当前版本都未经验证——别按固定数量做规划。

## FAQ

### 1. Breathedge 2 的铝在哪里？

车站郊区小行星带——大块岩石上的橙银色矿斑，不是列车旁的小散料。

### 2. 为什么我采不了铝？

你需要采矿器。撬棍和切割器对铝矿点无效。

### 3. 怎么找铝矿脉？

飞近大块小行星，直到出现「Aluminum deposits」+ Drill 提示——矿斑远看和岩石纹理一样。

### 4. 我需要多少铝？

核心套装 16 个：切割器 x4、钻孔器 x4、气罐 x4、背包 x4。

### 5. 铝会刷新吗？

没有确认——去挖新石头，别干等。
